# OCF Example Files

Each example is a self-contained, valid OCF v1.0.0 file demonstrating a specific scenario.

| File | Scenario |
|---|---|
| [01-minimal.ocf.json](01-minimal.ocf.json) | Smallest valid OCF file — no parts, no operations |
| [02-single-part-laser.ocf.json](02-single-part-laser.ocf.json) | One flanged plate, fiber laser cutting, S355 6 mm |
| [03-nesting-laser.ocf.json](03-nesting-laser.ocf.json) | Six different parts nested on a 3000×1500 sheet, full stats |
| [04-plasma-bevel.ocf.json](04-plasma-bevel.ocf.json) | Plasma cutting with A-profile bevel on outer edge (heavy plate) |
| [05-waterjet.ocf.json](05-waterjet.ocf.json) | Abrasive waterjet, granite tile cutting, quality 4 |
| [06-mixed-operations.ocf.json](06-mixed-operations.ocf.json) | Laser cut + drilling + tapping + marking on one sheet |
| [07-common-line-cutting.ocf.json](07-common-line-cutting.ocf.json) | Common-line (bridge-cut) constraint between two adjacent parts |

All coordinates are in millimetres. All angles are in degrees.
